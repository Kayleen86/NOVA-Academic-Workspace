# Contributing to NOVA

Thank you for helping improve NOVA — Academic Workspace!

## How to contribute

1. Open an issue describing a bug, improvement or documentation gap, or propose a pull request.
2. Work on a copy of the **generic NOVA template**, not on your personal study vault.
3. Keep all new documentation in English, consistent with the existing property names and numbered folder structure.
4. For changes to Dataview, Tasks or Zotero integrations, describe which plugin versions you tested and how to reproduce the behavior.
5. Test your change in Obsidian with at least one fictional course before submitting. GitHub does not render Obsidian's live dashboards.
6. Never include private information, grades, annotated papers, Zotero databases, purchased lecture slides, copyrighted materials, credentials or identifying screenshots.

Keep feature additions optional where possible. Prefer core Obsidian features, documented Dataview/Tasks queries and simple Markdown over unnecessary dependencies.

By submitting a contribution, you agree that it may be distributed under the repository's MIT License.
