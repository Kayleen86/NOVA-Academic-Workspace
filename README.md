# ✦ NOVA — Academic Workspace

**Your studies. Your knowledge. One organized workspace.**

NOVA is a free, customizable [Obsidian](https://obsidian.md/) vault template designed to help students manage their academic life in one place.

Organize courses, lecture notes, schedules, assignments, exams, and research literature without having to build an entire productivity system from scratch.

NOVA is designed to grow with you — from your first semester to your final thesis.

## ✨ Features

| Feature | What it does |
|---|---|
| 🎓 **Course Management** | Organize courses, materials, notes, and assignments in dedicated folders. |
| 📅 **Weekly Timetable** | Automatically display recurring classes based on your course information. |
| ✅ **Task Management** | Track assignments, deadlines, priorities, and completed work. |
| 📝 **Lecture Notes** | Create structured lecture notes with reusable templates and automatic indexes. |
| 🎯 **Exam Tracking** | Keep track of examination dates, registration status, and grades. |
| 📚 **Literature & Zotero** | Organize research papers, references, and reading notes with optional Zotero integration. |
| 🧠 **Knowledge Base** | Connect concepts, definitions, and information across different courses. |
| 📊 **Planning & Reviews** | Capture ideas, organize your workload, and review your weekly progress. |

## 🚀 Getting Started

NOVA comes with a ready-to-use folder structure, templates, and automatically generated dashboards.

1. Download this repository using **Code → Download ZIP**.
2. Extract the ZIP file, open the extracted repository folder, and select the `NOVA_Academic_Workspace` subfolder as your vault in Obsidian.
3. Install the required community plugins.
4. Follow the included setup checklist.
5. Copy the **Course Starter** folder to add your first course.

Your dashboards will automatically populate as you add courses, tasks, and examination dates.

**📖 [Read the Complete User Guide](NOVA_Academic_Workspace/docs/USER_GUIDE.md)** for step-by-step setup instructions, customization, and troubleshooting.

## 🧩 Requirements

- **Obsidian** — the note-taking application.
- **Dataview** — generates dynamic course, schedule, and exam dashboards.
- **Tasks** — provides automatic task and deadline management.
- **Templates** — Obsidian's built-in template functionality.

**Optional:** Zotero and the Zotero Integration plugin for academic literature management.

NOVA uses Markdown files and Obsidian properties. No programming knowledge is required.

## 💡 Good to Know

NOVA is an academic workspace template, not a standalone application.

- Automatic dashboards require Obsidian and the relevant plugins.
- Timetables support one regular weekly meeting per course by default; schedule changes are recorded separately.
- Zotero integration requires additional configuration.
- All courses, semester dates, and personal information are left empty for you to customize.
